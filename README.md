# blogs-posts

A collection of blog posts, written in Markdown.

## Structure

Each post lives in its own folder, named with the publish date and a short slug:

```
posts/
  YYYY-MM-DD-post-slug/
    index.md      # the post
    images/       # images used in the post (optional)
```

## Adding a new post

1. Create a folder under `posts/` named `YYYY-MM-DD-your-post-slug`.
2. Write the post in `index.md`, starting with a title and a short summary.
3. Put any images in an `images/` folder next to it and link them with relative paths.
4. Commit and push to `main`.
